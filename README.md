# Aussprache-Trainer · Wärmepumpen-Vokabular (EN / DE / FA)

Ein Vokabeltrainer mit **194 Fachbegriffen** aus dem Bereich Erneuerbare Energien /
Wärmepumpenprüfung. Jede Karte enthält:

- das Wort auf **Englisch, Deutsch und Persisch**
- einen **Lautsprecher-Knopf** für die englische und deutsche Aussprache (Ton ist offline eingebaut)
- ein **Beispiel** in drei Sprachen (englisches Beispiel antippen → Deutsch + Persisch)
- eine **Nummer** (passend zur Excel-Liste) und einen **Favoriten-Stern ⭐**

## Online öffnen (empfohlen)

Diese Seite ist über **GitHub Pages** erreichbar. Nach dem Aktivieren (siehe unten)
lautet die Adresse ungefähr:

```
https://DEIN-BENUTZERNAME.github.io/DEIN-REPO/
```

Über diese Adresse funktionieren in Chrome der Ton und das dauerhafte Speichern der Favoriten.

## GitHub Pages aktivieren

1. Repository öffnen → **Settings** → **Pages**.
2. Unter *Build and deployment* → *Source*: **Deploy from a branch** wählen.
3. Branch **main** und Ordner **/ (root)** auswählen → **Save**.
4. Nach ein bis zwei Minuten erscheint oben der Link zur fertigen Seite.

## Dateien

- `index.html` — der komplette Trainer (mit eingebettetem Ton, eine einzige Datei)

## Favoriten sichern

Über **Sichern / Laden** in der App bekommst du deine Favoriten als Zahlenliste
(z. B. `3, 17, 42`). Diese Liste kannst du kopieren und in einer neuen Version wieder
einfügen, damit deine markierten Wörter erhalten bleiben.
